# Changelog

Todas as alterações relevantes do **Machenike Hub** são documentadas neste arquivo.

## [1.0.0] - 2026-11-22

### Adicionado
- Suporte completo à linha Machenike: **G5 Pro Max**, **G5 Pro V2**, **G6 Pro**, **G5 Pro**, **G3 V2 / G3S** e **G1 / G1 Pro**.
- Detecção de conexão via **Receptor 2.4 GHz (Dongle USB 2.0)**, **Cabo USB** e **Bluetooth** (Web Gamepad API, WebHID e Web Bluetooth com bateria GATT) com memorização do modo por dispositivo.
- Interface de **Teste de Input em Tempo Real** na *Visão Geral*.
- **Modo Turbina / Disparo Rápido** (1–30 Hz por botão, modos *Segurar* e *Automático*).
- **Vibração Háptica Ajustável** com construtor de padrões multipasso e vinculação a eventos no jogo.
- **Sistema de Perfis de Jogo** (criar, salvar, carregar, duplicar, excluir, exportar/importar JSON).
- **Estúdio de Macros** com gravação ao vivo em `ms`, edição manual e simulação.
- **Iluminação RGB Multizona** adaptada por modelo.
- Suporte **PWA Offline** instalável no PC e Celular + workflows GitHub Actions para **GitHub Pages** e **GitHub Releases** (`.exe`, `.dmg` e `.AppImage`).
